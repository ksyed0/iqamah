- Prayer times with multiple adhan voices

## Iqamah Unique Differentiators

1. **macOS-native menu bar** with real-time countdown — only Guidance and Athan Pro match this; Guidance is broken on modern macOS
2. **Visual urgency indicator** — red status bar color under 10 minutes is unique across all 10 apps
3. **Separate Fajr adhan library** (3 distinct voices) — correctly reflects that the Fajr adhan differs from the other five prayers in Islamic practice
4. **Per-prayer minute adjustments** — only Muslim Pro, Athan Pro, and Namaz offer this
5. **Privacy-first** — no ads, no analytics, no tracking; shared only with Pillars and IslamApp
6. **Active maintenance on macOS 14+** — Guidance (the only true peer) is effectively abandoned

## Strategic Positioning

Iqamah's defensible position: **the well-maintained, privacy-respecting, macOS-native prayer time app** — the app that Guidance used to be, built for modern macOS.

**Highest-ROI additions (in order):**
1. **macOS widgets** — the menu bar already has all the data; WidgetKit extension is a natural next step
2. **Ramadan mode** — Suhoor/Iftar countdowns replacing the regular prayer countdown during Ramadan; 8/10 competitors have this and users expect it
3. **Silent / do-not-disturb mode** — adhan plays silently (visual only); Guidance had this, users loved it, no other macOS app offers it
4. **Exact GPS prayer times** — use `CLGeocoder` to resolve timezone from raw coordinates, eliminating the nearest-city rounding error (e.g. Brampton vs. Toronto)
